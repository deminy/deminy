# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This is `deminy/deminy` — a GitHub "profile README" repo. GitHub renders `README.md` from this repo on the user's GitHub profile page. There is no application code, build, lint, or test tooling here; the repo consists only of `README.md` and `CLAUDE.md`.

## Structure

- `README.md` — the profile content: bio and social links. All content is edited by hand; there is no automation (the former scheduled GitHub Action and its "Recent GitHub Activity" section have been removed).
